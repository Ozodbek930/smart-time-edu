Create a PROFESSIONAL IELTS MOCK TEST PLATFORM similar to CD IELTS.

IMPORTANT REQUIREMENT

The system must support a DYNAMIC PART SYSTEM.

Each exam section must allow the admin to ADD AS MANY PARTS AS NEEDED.

Admin should not be limited by fixed parts.

Example:

Listening → Admin can add multiple parts (Part 1, Part 2, Part 3, Part 4)

Reading → Admin can add multiple passages (Passage 1, Passage 2, Passage 3)

Writing → Admin can add multiple tasks (Task 1, Task 2)

Speaking → Admin can add multiple parts (Part 1, Part 2, Part 3)

Admin must be able to ADD / REMOVE / REORDER parts dynamically.
