Create a PROFESSIONAL IELTS MOCK TEST PLATFORM similar to CD IELTS.

The system must allow ADMIN to BUILD COMPLETE MOCK TESTS using PRE-CREATED PARTS.

MAIN IDEA
Admin first creates individual PARTS (Listening Part 1, Reading Passage 2, Writing Task 1 etc).
Then admin combines these parts to build a FULL MOCK TEST.

The mock test builder must work exactly like CD IELTS.

TECH STACK
Frontend: React + TailwindCSS
Backend: Node.js + Express
Database: PostgreSQL
Drag & Drop: dnd-kit
