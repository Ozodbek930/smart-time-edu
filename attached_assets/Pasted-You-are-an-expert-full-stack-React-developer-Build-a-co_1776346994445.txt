You are an expert full-stack React developer. Build a complete, clean, professional and bug-free **IELTS & CEFR Mock Test Platform** as a modern Single Page Application.

### Самая важная архитектурная задача:
Платформа должна быть полностью модульной и легко переключаемой между двумя режимами: **IELTS Mode** и **CEFR Mode**. 
Пользователь должен иметь возможность выбрать режим теста на главной странице или в настройках. 
В будущем должно быть легко добавлять новые режимы или использовать оба одновременно. 
Поэтому всё, что касается вопросов, типов заданий, тайминга, оценки и результатов — должно быть вынесено в отдельные конфиги и НЕ хардкодиться.

### Ключевые требования к модульности (CEFR-ready architecture):
- Создай центральный конфиг `testConfig` (или Context + config files), который содержит:
  - `mode: 'IELTS' | 'CEFR'`
  - Разные наборы вопросов и пулы для каждого режима
  - Разные тайминги секций (если нужны)
  - Разные типы вопросов и их количество
  - Разные системы оценки (scoring engine)
  - Маппинг результатов: IELTS (band 0–9) и CEFR (A1–C2 с descriptors)

- Scoring logic должен быть полностью отдельным: функция `calculateScore(answers, mode)` возвращает правильный формат результата в зависимости от режима.
- Все компоненты (Listening, Reading, Writing, Speaking) должны принимать `currentMode` как пропс и подгружать соответствующий контент, таймеры и типы вопросов.
- Результаты должны динамически показывать либо IELTS band score, либо CEFR уровень (с возможностью показывать оба в будущем).

### Основной пользовательский flow (строго соблюдать):
- Пользователь проходит тест строго по порядку: Listening → Reading → Writing → Speaking → Final Results.
- Нельзя пропускать или возвращаться к предыдущим секциям до завершения текущей.
- Используй state machine / wizard pattern для контроля потока.

### Система попыток (Attempts):
- Каждая новая попытка теста — отдельный attempt с уникальным ID и timestamp.
- Один пользователь может иметь много попыток. Попытки никогда не смешиваются.
- На главной странице показывать список предыдущих попыток с датой и результатом.

### Сохранение состояния и возобновление:
- Полное автосохранение: все ответы, текущая секция, текущий вопрос, оставшееся время.
- При перезагрузке страницы или закрытии вкладки — тест должен возобновляться точно с того же места.
- Используй Zustand + localStorage / IndexedDB для надёжного сохранения.

### Таймеры:
- Отдельный таймер для каждой секции (отображается крупно сверху).
- Listening, Reading, Writing — отдельные таймеры.
- Speaking — пошаговые таймеры по частям.
- Таймер работает только для текущей секции.

### Дизайн и UX:
- Очень чистый, минималистичный, профессиональный интерфейс (светлая тема, аккуратные акценты синего цвета).
- Никаких отвлекающих элементов — только то, что нужно для теста.
- Глобальная кнопка изменения размера шрифта (увеличить/уменьшить) — особенно важна для Reading и Writing.
- В Writing секции — отдельное управление размером текста внутри textarea.
- Sidebar navigator вопросов в Listening и Reading с индикацией (answered / unanswered / current).

### Детальные требования по секциям:

**Listening:**
- Надёжный аудиоплеер (play/pause, volume slider, кнопка Retry при ошибке).
- Поддержка разных типов вопросов: single MCQ, multiple selection, short answer, note/form completion, matching.
- Живые сохранение ответов.
- В конце — автоматическая оценка по точному answer key (НЕ AI).
- Детальная таблица результатов: Question | User Answer | Correct Answer | Status.
- Подготовить структуру для будущего CEFR mapping.

**Reading:**
- Тексты + вопросы, navigator, автосохранение, таймер.

**Writing:**
- Task 1 и Task 2.
- Textarea с подсчётом слов.
- Отдельное управление размером шрифта внутри редактора.
- Автосохранение.

**Speaking:**
- Пошагово (Part 1, Part 2, Part 3) с инструкциями и таймерами.
- Возможность записи ответа пользователя через MediaRecorder API.
